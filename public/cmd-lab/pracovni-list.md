# Zpráva počítačového detektiva

Vyplň údaje bez osobních identifikátorů. U každého uveď příkaz, výsledek a význam.

- [ ] Verze OS: …
- [ ] CPU a paměť: …
- [ ] Proces a PID: …
- [ ] Aktivní adaptér a DHCP: …
- [ ] Loopback a vzdálený ping: …
- [ ] DNS odpověď: …
- [ ] Počet kroků tracert (nebo důvod neúplnosti): …
- [ ] TCP stav a proces: …
- [ ] Rozdíl mezi hostitelem a VM (volitelné): …

Závěr: Co tě překvapilo? Které údaje bys neměl zveřejňovat?
