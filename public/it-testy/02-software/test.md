## 3. úloha

Jak se nazývá oprava nebo novější vydání programu?

[[aktualizace]]
<script>
const normalize = s => s.trim().toLowerCase().normalize("NFD").replace(/[\u0300-\u036f]/g, "");

</script>

Aktualizace může opravovat chyby.
