## 3. úloha

Jaká zkratka označuje systém překladu doménových jmen na IP adresy?

[[DNS]]
<script>
const normalize = s => s.trim().toLowerCase().normalize("NFD").replace(/[\u0300-\u036f]/g, "");

</script>

DNS vyhledává mimo jiné adresy pro jména.
