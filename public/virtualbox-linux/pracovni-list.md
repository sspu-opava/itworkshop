# Pracovní list – Linux v laboratoři

1. Zapiš RAM hostitele, volné místo, RAM a disk VM (bez osobních údajů).
2. Vysvětli vlastními slovy rozdíl ISO a VDI.
3. Před instalací ukaž učiteli nastavení disků. Potvrď, že je připojen pouze nový VDI a ISO.
4. Po restartu bez ISO vytvoř složku ITWORKSHOP a textový soubor.
5. V terminálu spusť pwd, ls, free -h. Co výsledky znamenají?
6. Vytvoř snímek vypnuté VM. Vytvoř cvičný soubor, vypni VM a obnov snímek. Popiš výsledek.
7. Uveď tři rozdíly mezi prostředím Windows a Linux Mint.
8. Vyber jednu další výzvu z článku. Popiš postup, výsledek a případnou chybu.

Nezapisuj heslo. Screenshoty pořizuj bez osobních údajů. Všechny kroky prováděj se souhlasem učitele.
