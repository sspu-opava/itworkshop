Otevři kurz **Vyzkoušej si Python**, nebo nainstaluj Python z [python.org](https://www.python.org/). V textovém editoru vytvoř soubor `ahoj.py` s tímto obsahem:

```python
print("Ahoj, světe!")
```

V příkazovém řádku Windows přejdi do složky se souborem a spusť `py ahoj.py`. Pokud příkaz nefunguje, ověř instalaci pomocí `py --version` nebo použij `python ahoj.py`, je-li tento příkaz dostupný.

Výsledkem je jeden řádek textu. Změň jej, přidej další `print` a program spusť znovu. Do online editorů nezadávej osobní údaje.
