V textovém editoru vytvoř soubor `index.html` a vlož do něj následující kód:

```html
<!doctype html>
<html lang="cs">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Můj první web</title>
  <style>body { font-family: sans-serif; color: #123; }</style>
</head>
<body>
  <h1>Můj první web</h1>
  <p>Právě vzniká moje stránka.</p>
</body>
</html>
```

Ulož soubor a otevři jej v prohlížeči. Změň text, obnov stránku a sleduj rozdíl. Potom přidej seznam tří zajímavých technologií.
